正在读取 Wi-Fi…

也可手动填写网络名称，包括隐藏网络。

测试使用当前填写的网络和密码，通过后请点击保存。

保存后退出 Passport 热点，设备会连接此网络校时；以后开机自动恢复准确时间。仅支持 2.4 GHz 网络。校时成功后关闭 Wi-Fi，蓝牙键盘照常使用。连接失败时会重试，也可手动同步时间。Wi-Fi 设置单独保存，不包含在情景导出文件中。

01 / 执行 双击和三击均为“无”时，短按松开立即发送单击；绑定双击或三击时等待 180ms。绑定三击后，双击等待第三击窗口结束，三击在第三次松开后发送。上下键长按 200ms；仅绑定长按时按下立即执行。单步保持到松开，多步只执行一次。OK 长按仍为 500ms。组合执行期间忽略新指令，长按 OK 可取消。

02 / 详情 标题显示在设备全屏详情中，副标题自动列出按键序列。完成后保留 0.5 秒。长内容换行，超出屏幕时省略。

连接与容量说明

最多 8 个情景，每个动作最多 64 步，全部配置共享 6 KiB 存储空间。支持设备字库中的基本汉字、英文及常用中文标点；不支持的字符会在保存前提示。预览使用浏览器字体，实际显示以设备为准。

Fn / 🌐 不支持；系统快捷键可能拦截录制，请手动选键。配对出现问题时，可清除设备上的配对记录，之后也请在电脑蓝牙设置中忽略 Passport Keys。
