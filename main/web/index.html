连接与容量说明

最多 8 个情景，每个动作最多 64 条动作，按键配置共用 6 KiB。名称与标题最多 16 字，保存前检查设备字库支持。

双击和三击未设置时，单击立即发送；配置后等待 180 ms 判定。上下键长按 200 ms；仅配置长按时按下即执行。单步保持至松开，多步执行一次。

OK 长按 500 ms 为全局返回；执行组合期间可取消。标题显示于设备详情，副标题由步骤自动生成；完成后保留 0.5 秒，长内容换行或省略。网页预览使用浏览器字体，实际显示以设备为准。

Fn / 🌐 不支持；系统拦截的快捷键请手动选键。时区为固定 UTC 时差，夏令时需手动调整；取得有效时间前，设备显示 --:--。

保存 Wi-Fi 后退出配置即可校时，以后开机自动连接。同一局域网打开 http://192.168.1.11/config 可自动配置；最后一个配置页面关闭后立即恢复监听。突然断网由 120 秒心跳确认离线。打开文件流转页可切换功能，旧页面需手动重新连接。完整配置导出包含 Wi-Fi 密码，请妥善保管。

退出配置后，需在设备上确认。
