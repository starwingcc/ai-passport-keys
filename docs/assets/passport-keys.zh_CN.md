# Passport Keys

将三键 AI Passport 变成可配置的蓝牙键盘，无需电脑常驻软件。

## Agent 开发入口

先读 [AGENTS.zh_CN.md](../../AGENTS.zh_CN.md)、[AI 开发指南](../development/ai-guide.zh_CN.md)
和必需的 [Passport 技能](../../skills/README.zh_CN.md)。应用代码在 `main/main.c`、
`main/keyboard/`，网页在 `main/web/`。板级逻辑复用 `components/bsp`，
设备文字遵循[字体指南](../../assets/README.zh_CN.md#passport-keys-字库)。
测试位于 `tests/`；修改期间运行静态门禁，交付前运行完整门禁。
刷机、设备测试及 Git 写入需要用户授权。

## 使用

在电脑蓝牙设置中配对 **Passport Keys**。上下键选择**开始控制**、**情景列表**或**设置**，
短按 OK 进入，长按 OK 返回或取消当前动作；进入开始控制后发送按键。

| 按键 | 单击 | 双击 | 三击 | 长按 |
| --- | --- | --- | --- | --- |
| 上 | 无 | 撤销 | 重做 | 保持左 Option/Alt，名称为“可配置为语音输入” |
| 下 | 删除（Backspace） | 无 | 无 | 全选并删除 |
| OK | 回车 | 无 | 无 | 返回／取消 |

初始情景名称为 **coding模式**。这些默认动作在首次初始化及恢复默认后生效，
升级会保留已保存的情景。请在**配对设备**中选择对应系统：macOS 使用 Command+Z、
Shift+Command+Z 和 Command+A，Windows 使用 Control+Z、Control+Y 和 Control+A。
全选后执行一次 Backspace 删除。“可配置为语音输入”是 Alt 长按动作的名称，
语音输入快捷键需按电脑端设置配置。

设置顺序为**屏幕 → 配对设备 → 文件流转 → 系统配置 → 清除蓝牙配对**。

- **屏幕**：调整亮度及空闲变暗／息屏计时，0 表示关闭计时。
  上下键调整，短按 OK 保存，长按 OK 取消；息屏后首次按键只唤醒，松开后再操作。
- **文件流转**：在设备上主动开启后，同一局域网打开 `http://192.168.1.11` 或 `/transfer`。
  上下键选择关闭（上方）或开启（下方），短按 OK 执行，`>` 标记光标，`*` 标记运行状态。
  长按 OK 返回后仍保持开启，蓝牙键盘可用；选择关闭才结束服务。
  未配置 Wi-Fi 时先通过本机热点配置。文件流转和系统配置菜单项显示“已关闭”“连接中”“已开启”或“已连接”。
  网页访问不能开启或切换功能，退出配置也不会自动开启文件流转。
- **配对设备**：保存 A、B 两套记录，每台独立保存 macOS／Windows。
  选择空槽位后短按 OK 新增设备，长按 OK 取消；记录已满时不会自动覆盖。
  设备操作页提供**切换设备**和**修改操作系统**。切换后只连接一台设备，
  休眠的电脑可能需要在蓝牙设置中主动重新连接。选择已连接设备会保留连接。
  切换目标保存成功后直接进入开始控制页，输入仍需等待目标设备连接且 HID 就绪。
- 配对成功立即进入**操作系统**页。上下键选择，OK 保存，`>` 标记光标，`*` 标记已保存系统。
  该设备的系统成功保存前，键盘、媒体键和宏均禁用。
  系统保存成功后直接进入开始控制页；已连接但未保存系统时，页面顶部显示“需配置操作系统”。
  修改期间暂停输入，长按 OK 取消并保留原设置；保存失败保留原值，可重试。
  切换和重启自动恢复各设备的系统。旧版全局系统设置升级后需按设备身份确认一次。
- 尝试读取电脑名称；不可读、为空、字形不支持或过长时显示**设备 A／B**，名称不会用于判断系统。
- **清除蓝牙配对**：确认后清除两台设备的密钥、名称和系统，重新开放首次配对。
  重新配对前请在对应电脑上忽略 Passport Keys。快捷键、宏和情景保留。
- **配对恢复**：电脑请求本机已不存在的密钥时，首页和控制页会提示在电脑蓝牙设置中
  忽略／删除 Passport Keys 后重新配对。本机没有配对记录且未加密连接连续失败时，
  显示可能保留旧配对的提示。提示在反复重连期间保持稳定，安全连接成功后自动消失；
  本机菜单和返回仍可使用。

## 网页配置

1. 已保存可用 Wi-Fi 后，进入**设置 → 系统配置 → 通过 WiFi**主动开启，
   再在同一局域网打开 `http://192.168.1.11/config`（根地址也进入配置页）。
   蓝牙键盘保持连接；开启配置会结束文件流转。
2. 首次配网进入**设置 → 系统配置 → 通过本机热点**，连接屏幕显示的热点，
   打开 `http://192.168.4.1`。本机热点会暂停蓝牙，仍需手动退出。
3. 编辑工牌、Wi-Fi 网络、情景及键盘／媒体步骤，步骤为空即禁用动作；**设为当前**选择当前情景。
   选择实体按键和单击／双击／三击／长按，再用**录制**或**手动选键**编辑键盘步骤。
   点击**保存全部设置**后，工牌和按键立即更新，保留当前页面和息屏状态。
   按键配置变化会停止旧宏并释放按键；仅修改工牌时不中断宏。
   Wi-Fi 修改在退出后生效，以保持网页连接。点击**退出配置**或在设备长按 OK 退出。
   保存失败时保留已保存的设置，请保持页面打开并重试。

配置和文件流转直接进入功能页面，连接状态及重试均在当前页面内完成。

配置持续开启，直到主动退出；关闭全部网页或心跳超时只清理页面连接。
页面加载和加入有 30 秒期限，在线页面使用 120 秒心跳超时；这些计时不会关闭设备上的功能。
扫描、网络测试及恢复、保存完成安全清理后再退出。访问 `/transfer` 不会切换功能。
旧编辑页保留未保存草稿；设备重新开启系统配置后，点击**重新连接**可恢复编辑，不会自动保存。
本机热点配置也需要主动退出。

开机使用已保存的 Wi-Fi 校时，校时完成后仍保留连接到开机满两分钟，期间不自动启动网页服务。
文件流转或配置一旦主动开启，就持续持有 Wi-Fi；校时完成、失败或开机满两分钟都不会关闭正在使用的连接。
主动退出后，开机未满两分钟则保留到原截止时间，已满则在清理完成后断开；不重新计时。
后续定期校时和失败重试保留，同样不会中断手动开启的功能。

每条键盘或媒体动作可选择**全部**、**Windows**或**Mac**。设备依据当前设备已保存的系统，
执行全部及匹配系统的动作，跳过其他动作及其等待。相邻 Windows/Mac 动作共享编号和步骤卡片；
可整组移动、删除，也可分别编辑或删除分支。底部两种系统的实际执行预览使用共享编号。
设备显示预览和实机指令摘要均依据设备已保存的系统筛选。
限制按实际动作计算：每个手势最多 64 条，全部情景共用 6 KiB。

**Ctrl**、**Shift**、**Option/Alt**、**Command**是独立的固定修饰键。
加载或导入旧配置时，左右 Cmd/Ctrl 转为对应的固定 Command；缺少适用系统时默认为全部。
长按仅有一条可执行动作时保持到松开，多条可执行动作运行一次。

**工牌首页**设置身份、头像、UTC 时差及 12／24 小时制。
名称和短标签最多 16 个支持的字符，取得有效时间前首页显示 `--:--`。
Wi-Fi 需要 2.4 GHz 网络。两种配置方式都支持扫描和连接测试；取得 IP 即测试通过，无需校时，测试不会保存凭据。
通过 WiFi 测试时，页面会暂时断开，成功、失败或超时后恢复原网络。
候选网络测试临时使用 DHCP，恢复原网络时重新设置固定地址及 DNS。
请保持页面打开等待自动重试，恢复失败时可改用本机热点配置。网络修改在保存并退出配置后生效。

**导出完整配置**备份工牌、Wi-Fi 和全部按键情景，包含明文 Wi-Fi 密码，请妥善保管文件。
导入会将配置加载到编辑区，保存后生效；单情景导出只分享按键，导入时保留当前工牌与 Wi-Fi。

**恢复默认配置**在保存后重置工牌、Wi-Fi 与全部按键情景。
屏幕、各设备系统及蓝牙配对设置仍独立于这份配置。

## 局域网浏览器流转

先在**设置 → 文件流转**选择开启，再在同一局域网打开
`http://192.168.1.11` 或 `http://192.168.1.11/transfer`。为浏览器取名，选择指定设备或所有在线设备后发送文字，
或共享文件供接收端点击接收。**Enter** 发送文字，**Shift+Enter** 换行。
文字记录显示发送目标和接收确认，点击**复制**即可复制文字。
最多四个浏览器会话，每个发送端最多共享八个文件。

固件使用 `192.168.1.11`，掩码 `255.255.255.0`，网关和 DNS 均为 `192.168.1.1`。
使用前核实该地址属于 Passport，并在路由器中保留或排除该地址。
其他网段可能不兼容，固件不会悄悄改用其他地址。

浏览器成功加入且会话未失效时才算在线。关闭页面会清理该页面的会话与共享文件，
设备上的文件流转仍保持开启，可再次打开网页加入。页面加载和加入有 30 秒期限，突然断网使用 120 秒心跳超时。
在设备上关闭文件流转后，HTTP 服务完全停止；网页的**重新连接**只能加入设备已经开启的功能。
打开 `/config` 不会切换功能，需在设备菜单进入系统配置。Wi-Fi 继续使用调制解调器省电。

保持页面打开，手机保持前台。刷新或关闭页面会结束该页面的传输、移除共享文件，
并丢失尚未保存的接收文件。Passport 不缓存或中继内容。
流转使用本地 WebRTC，不需要摄像头或麦克风权限；无法连接时检查网络隔离、
防火墙或 WebRTC 限制，必要时更换浏览器。

进度显示在对应文件下方，接收并校验完成达到 100% 后，右侧的**取消**变为**保存文件**。
请在浏览器中确认下载结果。电脑和手机每个页面的接收总容量均为 1024 MiB，
等待接收、正在接收和尚未保存的下载共用此容量，保存或取消会释放容量。
实际接收能力取决于浏览器和设备。支持直接保存时，在接收时选择位置，完成后自动保存。

## 构建与刷写

按[环境指南](../development/engineering/environment-setup.zh_CN.md)激活 **ESP-IDF 5.5.3**。
设备开机并用 USB 数据线连接后，在仓库根目录执行：

```sh
./tools/validate.sh
python -m serial.tools.list_ports
PASSPORT_PORT=/dev/cu.usbmodemXXXX  # 替换为实际检测到的端口。
python -m esptool \
  --chip esp32c3 --port "$PASSPORT_PORT" --baud 460800 \
  --before default_reset --after hard_reset \
  write_flash --flash_mode dio --flash_freq 80m --flash_size 8MB \
  0x10000 build/FoloToy-AI-Passport.bin
```

现有分区布局兼容时，仅更新应用可保留 NVS。
首次安装或有意完整刷新时，将末行替换为 `0x0 build/FoloToy-AI-Passport-full.bin`，
**这会重置已保存设置及配对**。参见[刷写与数据政策](../development/engineering/firmware-layout.zh_CN.md#烧录与已存数据)。
完整刷新后，请在电脑端忽略旧的 Passport Keys 配对，再重新配对，让两端使用新的配对密钥。
